# RTL Atlas Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline for this implementation.

**Goal:** Build a bilingual Mac-oriented RTL reader with real elaboration and optional Codex assistance.
**Architecture:** React/React Flow renders a parser-owned neutral graph. Electron owns project selection, a compiled pyslang sidecar and Codex stdio transport.
**Tech Stack:** TypeScript, React, React Flow, Dagre, Electron, Python/pyslang.
**Spec:** docs/superpowers/specs/2026-10-16-rtl-atlas-design.md

## Global Constraints
- Chinese/English switch, no corner icon, read-only RTL.
- No invented parser results or assistant responses.
- Mac builds require a Mac runner; bundled parser requires no end-user Python.

## Review Focus
- Parameterized/generate instances must retain unique identities and widths.
- Unconnected ports/constants must not be invented as driven data paths.
- Compiler failures must not replace the last usable graph.
- Child crashes/cancellation must clear pending assistant operations.
- Locale changes must preserve selection and not translate source identifiers.
