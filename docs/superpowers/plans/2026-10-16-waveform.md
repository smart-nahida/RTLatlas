# Waveform and API tools Implementation Plan

> Implement inline using superpowers:executing-plans and test-driven-development.

Goal: API dialogue creates TB/teaching stimuli, runs local simulation, and opens an original-layout collapsible waveform panel.
Architecture: Electron owns bounded filesystem and simulator tools. AssistantClient exchanges standard tool_calls and tool result messages. Shared VCD data feeds a React waveform viewer, graph values, and AI cursor context.
Spec: docs/superpowers/specs/2026-10-16-waveform-design.md

## Constraints
No new dependencies, arbitrary shell, fixed generation button or explanatory small captions. Writes stay in .rtl-atlas/sim/<scene>/; project symlinks/traversal and secret files are rejected. Existing non-Git workspace is the authorized target.

## Review focus
- Chunked SSE tool argument assembly and whole-turn history truncation.
- Cancel or timeout during compile/run, no orphan simulator process.
- VCD unknowns, aliases, time scaling and incomplete records.
- Collapse-to-zero and reopening at previous height without obstructing graph.
- Real project/source mapping and stale waveform after switching projects.
